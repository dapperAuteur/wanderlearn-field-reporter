## Block 3 — Word-for-word VO (verbatim)

**[Beat 1 · talking-head · 0:00]**
> The capstone's belief, and the whole course's test: you can redeploy the reflection-loop pattern
> without the notes, on a domain you have never seen. Five modules built the stack on support replies.
> Now we compose all of it on a different domain: rewriting dense legal clauses into plain language.

**[Beat 2 · slide: the clause · 0:35]**
> Why a new domain, deliberately? A course that tested you on the domain you learned would prove only
> that you can follow a recipe. The point of Foundation is a model you carry to new problems. So the
> capstone switches domains on purpose. Here is a real public-domain clause: when the process of freeing
> a vehicle that has been stuck results in ruts or holes, the operator will fill the rut before removing
> the vehicle. The loop's job: make that readable.

**[Beat 3 · editor: the import list · 1:40]**
> And here is the proof that the pattern transfers, and it is mechanical. Open the capstone and read what
> it imports. Score-against-rubric from Module 2. Route-with-all-patterns and the state from Module 1.
> Pairwise, threshold, assert-no-infra-errors from Module 4. Compute-metrics and pareto-frontier from
> Module 5. Everything structural is reused unchanged. The capstone writes only domain data: a new rubric,
> a new corpus, offline stand-ins. That is the entire deliverable.

**[Beat 4 · slide: the reuse table · 3:00]**
> The whole stack composes. The cycle from Module 0. The bounded router from Module 1. The rubric scorer
> from Module 2. The trace shape from Module 3. The eval comparisons from Module 4. The metrics and Pareto
> from Module 5. New: only the rubric and the corpus. If you understood the five modules, you can build
> this capstone by writing a rubric and a dataset and wiring parts you already have.

**[Beat 5 · talking-head · 4:00]**
> The capstone is not a seventh idea. It is the six you already have, composed on new ground. The fact
> that you can run the whole stack on legal-clause rewriting by writing only a rubric and a dataset is the
> durable mental model the course set out to install. Next, we build that rubric.
